# Base del alumnado

JavaFX con FXML, Maven y PostgreSQL.

- Abre esta carpeta (pom.xml) como proyecto Maven en IntelliJ.
- Usa JDK 17 o 21 y revisa src/main/resources/db.properties.
- Ejecuta `mvn clean javafx:run` o el objetivo javafx:run del panel Maven.
- Consulta ../02_Guia para el montaje y los ejercicios.
- Scripts compartidos en ../sql: no se ejecutan automáticamente desde Java.
